# Xiaomi SU7 Digital Cockpit

پنل سه‌بخشی راننده با حفظ ساختار نسخهٔ قبلی: اطلاعات ثابت راننده، نمای سه‌بعدی مرکزی، منوهای کنترل و نوار تهویهٔ دو ناحیه‌ای. مدل Xiaomi SU7 از فایل USDZ ارسال‌شده توسط کاربر تبدیل شده است.

## استفادهٔ کارفرما

فایل `g-class-cockpit.html` را با گزینهٔ Download raw file دانلود و در Chrome، Edge، Firefox یا Safari به‌روز باز کنید. نصب، حساب کاربری، سرور یا اینترنت لازم نیست. نام فایل برای حفظ لینک و ساختار قبلی تغییر نکرده است؛ محتوای آن اکنون SU7 است.

منوها: خودرو، دسترسی، تهویه، صندلی، نور محیط و سفر. نمایشگر برای ابعاد 1920×720 و نمایشگرهای کوچک‌تر تنظیم شده است. تنظیمات از دکمهٔ بالای پنل باز می‌شوند. Escape پنجرهٔ تنظیمات را می‌بندد. حالت تمرکز، بخش کنترل‌ها را جمع می‌کند. خاموش‌کردن نمایشگر از پنجرهٔ تنظیمات قابل انجام است و با دکمهٔ روشن‌کردن پنل بازمی‌گردد. تنظیمات آسایش و ظاهر در مرورگر همان دستگاه ذخیره می‌شوند؛ قفل، درها و اطلاعات سفر فرمان واقعی خودرو نیستند.

## مدل و محدودیت‌ها

هندسه و بافت‌های مدل ارسالی حفظ شده‌اند؛ بافت‌ها به WebP و هندسه به GLB با Meshopt تبدیل شده‌اند. حدود 90,230 مثلث و اندازهٔ مدل بهینه حدود 1.8 MB است. فایل HTML نهایی شامل مدل، کد و فونت، حدود 3.4 MB است. ریگ یا انیمیشن در در فایل USDZ وجود ندارد؛ کنترل دسترسی وضعیت‌ها را در رابط نمایش می‌دهد و هندسهٔ درها را تغییر نمی‌دهد. کابین همان جزئیات موجود در فایل ارسالی را دارد. داده‌های رانندگی نمونه‌اند و هیچ اتصال ECU/CAN در این نمونه وجود ندارد.

## توسعه

کد خوانا در `cockpit-src/` قرار دارد؛ HTML خروجی برای استفادهٔ مستقیم کارفرماست.

```sh
npm install
npm run build
```

نیازمندی ساخت: Node.js 22 یا جدیدتر. ساخت دوباره، مدل جاسازی‌شده را از HTML موجود می‌خواند. HTML موجود را پیش از ساخت حذف نکنید. `app.js` شامل وضعیت و کنترل‌ها و موتور نمایش است، `styles.css` شامل تم و چیدمان است و `index.template.html` ساختار نمایشگر را نگه می‌دارد. رویداد محلی `cockpit:change` یک نسخه از وضعیت و پرچم `simulation: true` را برای توسعهٔ آداپتور آینده ارائه می‌کند؛ هیچ فرمان شبکه‌ای صادر نمی‌شود. برای جایگزینی مدل، یک فایل GLB بهینه را با نام `SU7.optimized.glb` کنار HTML قرار دهید و دوباره بسازید.

Three.js 0.186.1، Meshoptimizer 1.3.0، esbuild 0.28.2 و Vazirmatn 5.3.0 نسخه‌های ثابت این خروجی‌اند. رندر روی WebGL2 اجرا می‌شود تا روی نمایشگرهای فعلی قابل استفاده باشد؛ در حالت ثابت و تب مخفی متوقف می‌شود و در تعامل‌ها سقف 30 FPS دارد. کیفیت خودکار تراکم پیکسل را در صورت هزینهٔ بالای رندر کاهش می‌دهد. کیفیت اقتصادی و بالا نیز در تنظیمات قابل انتخاب‌اند.

## بررسی

بارگذاری GLB بدون درخواست خارجی، کنترل‌های قفل و درها، دمای مستقل و SYNC، تناقض گرمایش/تهویهٔ صندلی، ذخیرهٔ تنظیمات پس از بارگذاری مجدد، بستن پنجره با Escape و چیدمان‌های 1920×720، 1024×600 و 390×844 در Chromium بررسی شدند. در نمای ثابت، شمارش فراخوانی‌های رسم در بازهٔ بررسی صفر بود. این بررسی، تأیید استفادهٔ تولیدی در خودرو یا آزمون سخت‌افزار نهایی نیست.

مجوز کتابخانه‌ها و فونت در `THIRD_PARTY_NOTICES.txt` آمده است. مدل از فایل کاربر تأمین شده است.
