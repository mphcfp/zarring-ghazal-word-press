# Xiaomi SU7 Driver Cockpit — v3

پنل راننده با حفظ چیدمان سه‌بخشی: اطلاعات راننده، مدل سه‌بعدی SU7، کنترل‌های سریع و نوار دائمی دمای دو ناحیه‌ای. فایل `g-class-cockpit.html` برای حفظ لینک نسخه‌های قبلی همین نام را دارد.

## اجرای مستقیم

فایل HTML را با Download raw file دانلود کنید و در Chrome، Edge، Safari یا Firefox به‌روز باز کنید. مدل، فونت و کتابخانه‌ها داخل همان فایل‌اند؛ نصب یا اینترنت لازم نیست.

## اولویت کنترل‌ها

- **خانه:** بخارزدایی جلو، فلاشر، چراغ‌ها، A/C، سرعت فن، گردش داخلی و تهویه خودکار.
- **همیشه در دسترس:** تنظیم دمای راننده و سرنشین از نوار پایین.
- **همهٔ امکانات:** دسترسی به درها و صندوق، صندلی، نور محیط، اطلاعات سفر و تنظیمات نمایشگر. امکانات غیرضروری در حرکت محدودند.
- **روی مدل:** نشانه‌های درها، صندوق و کاپوت با لمس باز و بسته می‌شوند. نمای جلو و عقب برای دسترسی به نشانه‌های مربوط به همان سمت فراهم است.

## حرکت واقعی قطعات مدل

فایل USDZ کاربر ریگ آماده نداشت. قطعات درها، شیشه‌های جانبی، دستگیره‌ها، آینه‌ها، صندوق و کاپوت تفکیک و برای آن‌ها لولای مستقل بازسازی شده است. این لولاها بازسازی تقریبی برای نمایش تعاملی‌اند و مدل رسمی مهندسی خودرو نیستند. هندسهٔ اصلی حدود 90,230 مثلث دارد؛ محفظه‌های داخلی صندوق و جلو برای نمای باز تکمیل شده‌اند. مدل با Meshopt و WebP فشرده شده است.

## قفل فرمان‌ها در حرکت

دسترسی فقط وقتی مجاز است که دادهٔ معتبر و تازه، هم‌زمان **سرعت صفر + دنده P + ترمز پارک فعال** را نشان دهد. حرکت، دندهٔ غیر P، ترمز پارک غیرفعال، دادهٔ ناقص، نامعتبر یا منقضی باعث رد فرمان‌ها می‌شود. وضعیت قفل مرکزی نیز جداگانه بررسی می‌شود. همین سیاست برای کلیک روی نشانه، منوی دسترسی و API اعمال می‌شود؛ مخفی‌کردن دکمه تنها کنترل حفاظتی نیست.

فرمان‌های دسترسی، شخصی‌سازی، دوربین، ذخیرهٔ تصویر و خواب نمایشگر هنگام حرکت مسدودند. فلاشر، چراغ‌ها، بخارزدایی و تهویه برای راننده در دسترس می‌مانند. شروع حرکت نمایشی تا بسته‌شدن کامل انیمیشن همهٔ بخش‌ها رد می‌شود. دریافت حرکت در میانهٔ انیمیشن، حرکت لولا را متوقف می‌کند؛ مدل خودبه‌خود در را نمی‌بندد. اگر در یا صندوق در حال حرکت باز باشد هشدار نشان داده می‌شود.

## امتحان‌کردن حالت حرکت

در ستون راننده، دکمهٔ **شروع حرکت نمایشی** سرعت نمونهٔ 48 km/h و دنده D را فعال می‌کند. برای بازگشت به پارک از **توقف شبیه‌سازی** استفاده کنید. دادهٔ حرکت ذخیره نمی‌شود و بعد از بارگذاری مجدد حالت نمایشی پارک آغاز می‌شود.

این فایل به خودرو یا CAN/ECU متصل نیست. تشخیص حرکت واقعی به آداپتور سخت‌افزار و سیگنال معتبر نیاز دارد. قفل این نمونه یک سیاست رابط است؛ جای قفل سخت‌افزاری یا اعتبارسنجی سیستم واقعی خودرو را نمی‌گیرد.

## رابط آداپتور

در همان صفحه، برای آزمایش یا توسعه:

```js
// یک بستهٔ کامل و اتمیک؛ زمانِ دریافت در صورت نبود timestamp استفاده می‌شود.
window.SU7Cockpit.setTelemetry({
  speed: 32,
  gear: 'D',
  parkingBrake: false,
  timestamp: Date.now()
});

// وضعیت خواندنی، شامل حرکت و زاویهٔ جاری لولاها.
window.SU7Cockpit.getSnapshot();

// در جلو چپ، جلو راست، عقب چپ، عقب راست، صندوق، کاپوت: 0 تا 5.
// این مسیر نیز از قفل فرمان عبور می‌کند؛ فرمانی به خودرو ارسال نمی‌کند.
window.SU7Cockpit.requestAccess(4, true);
```

رویداد `cockpit:telemetry` با همان detail نیز پذیرفته می‌شود. دادهٔ آداپتور پس از 2 ثانیه بدون به‌روزرسانی منقضی می‌شود. سرعت باید عدد متناهی 0 تا 300، دنده یکی از P/R/N/D و وضعیت ترمز پارک یک boolean باشد. بستهٔ قدیمی‌تر نمی‌تواند وضعیت جدیدتر را به پارک برگرداند. برای آزمایش پارک، بستهٔ سرعت صفر، دنده P و parkingBrake=true را مرتب به‌روز کنید. رویدادهای محلی `cockpit:change` و `cockpit:motion` برای هماهنگی رابط منتشر می‌شوند. این API به‌تنهایی اصالت یا صحت دادهٔ ECU را تأیید نمی‌کند.

## تغییر کد و ساخت

Node.js 22 یا جدیدتر:

```sh
npm install
npm run build
npm test
```

- `cockpit-src/app.js`: کنترل‌ها، صفحهٔ اصلی، منوها، مدل، لولاها و نشانه‌ها.
- `cockpit-src/motion.js`: اعتبارسنجی دادهٔ حرکت و سیاست مشترک قفل فرمان.
- `cockpit-src/styles.css`: تم، اندازهٔ لمس و چیدمان نمایشگرها.
- `cockpit-src/index.template.html`: ساختار پنل.
- `cockpit-src/build.mjs`: خروجی HTML آفلاین.

HTML موجود را قبل از build حذف نکنید؛ مدل جاسازی‌شده از آن استخراج می‌شود. مدل جایگزین باید GLB دارای گروه‌های `access_0` تا `access_5` باشد. بسته‌های اجرا: Three.js 0.186.1، Meshoptimizer 1.3.0 و Vazirmatn 5.3.0؛ بستهٔ ساخت: esbuild 0.28.2. رندر در نمای ثابت متوقف و در تعامل‌ها به 30 FPS محدود می‌شود؛ کیفیت خودکار، اقتصادی و بالا قابل انتخاب‌اند.

## بررسی

تست‌های سیاست حرکت در `tests/motion.test.mjs` شامل سرعت مثبت، دنده، ترمز پارک، دادهٔ ناقص/نامعتبر/قدیمی و انقضا هستند. مرورگر نیز برای حرکت واقعی لولاها، بازشدن صندوق، رد شروع حرکت با درِ باز، رد دسترسی از API در حرکت، حفظ کنترل‌های ضروری، توقف انیمیشن هنگام حرکت، رندر بی‌کار و نمایشگرهای عریض و کوچک بررسی شده است. این بررسی‌ها آزمون سخت‌افزار نهایی یا تأیید استفادهٔ تولیدی خودرو نیستند.

مجوز کتابخانه‌ها و فونت در `THIRD_PARTY_NOTICES.txt` آمده است. مدل از فایل ارسال‌شده توسط کاربر تأمین شده است.
